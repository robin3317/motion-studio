# feature-grid
**Use for:** 2–4 services, features or selling points.  **Length:** 3–5 s
**Needs:** short titles (≤ 4 words) + optional icons (original line icons or free-licensed sets).
**Beats**
- 0.0–0.8: cards cascade in (stagger 0.12 s): rise 30 px + fade, or pop with scale
- Then each card highlights briefly in turn (accent border or icon bounce) as the VO mentions it
- 9:16: stack vertically; 16:9: a row of 3 or a 2×2 grid
**Ease:** `power3.out` / `back.out(1.5)` (playful).  **SFX:** grouped: one swish for the cascade, soft ticks on the highlights.
**Avoid:** paragraphs inside cards; more than 4 cards.
**Registry starting points:** grid-card-assemble, stagger-cascade, staggered-fade-up, split-tilt-cards. Check availability with the `/hyperframes-registry` skill (the catalogue changes). Restyle the block to the preset; don't ship it unchanged.
