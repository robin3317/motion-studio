# Shot recipe cards

Each card is one reusable animation idea. Times are relative to the shot start. Scale motion by the style preset (e.g. Minimal Luxury ≈ 1.5× slower, Bold Kinetic ≈ 0.7×). Build the actual markup with the `/hyperframes` skill. Each card lists **registry starting points**: ready-made HyperFrames blocks to install and restyle before hand-building.

| Card | Category | Typical length | Playbooks |
|---|---|---|---|
| `logo-assemble.md` | Opening / brand | 1.5–3 s | company, brand, release |
| `kinetic-title.md` | Typography | 1.5–4 s | all |
| `3d-logo-reveal.md` | 3D / brand | 2.5–4 s | brand, release, product |
| `product-hero-orbit.md` | 3D / product | 2.5–5 s | product |
| `product-float-callouts.md` | Product | 3–5 s | product |
| `device-mockup-screens.md` | UI / product | 3–6 s | product, company |
| `stat-counter.md` | Data | 2–3.5 s | company, product, release |
| `logo-wall.md` | Data / proof | 2.5–4 s | company |
| `feature-grid.md` | Info | 3–5 s | company, product, release |
| `parallax-push.md` | Camera / 2.5D | 2–4 s | all |
| `shape-wipe.md` | Transition | 0.4–0.8 s | all |
| `countdown-flip.md` | Release | 2–4 s | release |
| `lower-third.md` | Footage overlay | 3–4 s | footage-edit |
| `caption-highlight.md` | Captions | continuous | footage-edit, any VO video |
| `cta-end-card.md` | Outro | 2.5–4 s | all |

Rules: don't use the same card twice in a row; vary scale (wide → close) and direction between consecutive shots; every card's SFX cue is optional, so follow `audio.md` placement rules.
