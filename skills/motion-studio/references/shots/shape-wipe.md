# shape-wipe
**Use for:** transitions between scenes.  **Length:** 0.4–0.8 s
**Needs:** the style's shape language (rectangle bars, circles, diagonal slabs, blobs).
**Beats**
- 0.0–0.35: shape(s) sweep in covering the frame (brand colours, 2–3 layered offsets 0.04 s apart)
- At full cover: cut the scene underneath
- 0.35–0.7: shapes sweep out, revealing the next scene
**Ease:** `power4.inOut` / `expo.inOut`.  **SFX:** one swish timed so its peak hits full cover.
**Variants:** circle iris (Playful), diagonal slabs (Bold), thin line sweep (Clean), grid columns (Editorial).
**Avoid:** using it between every scene; mix with straight cuts.
**Registry starting points:** transitions-cover, directional-wipe, iris-reveal, transitions-push. Check availability with the `/hyperframes-registry` skill (the catalogue changes). Restyle the block to the preset; don't ship it unchanged.
