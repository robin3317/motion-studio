# Style: Tech Neon
**Feel:** dark, glowing, futuristic, precise.
- **Background:** near-black (#07080C to #0E1117), subtle grid or dot matrix, glow gradients.
- **Colour:** 1–2 neon accents (the brand colour pushed bright: cyan, violet, lime…) on dark. Glow with restraint.
- **Type:** Space Grotesk / Inter + JetBrains Mono for labels and code. Monospace counters and tags.
- **Motion:** precise and techy. Ease `power3.out`. Line draws, scanline wipes, typewriter or decode text for **Latin labels only** (complex scripts: reveal by word). Entrances 0.3–0.5 s.
- **Transitions:** glitch slices (subtle, ≤ 3 frames), light streaks, grid zooms.
- **Graphics:** UI panels, glass cards, node graphs, code snippets, real product screenshots with glow frames.
- **Shots:** `device-mockup-screens`, `stat-counter`, `feature-grid`, `parallax-push`, `3d-logo-reveal`, `cta-end-card`.
- **Music:** synthwave / electronic / tech house, 110–128 BPM. **SFX:** digital blips, data chirps, synth whooshes, bass hits.
- **Avoid:** overusing glitch, unreadable glow on text, pure neon on neon.
